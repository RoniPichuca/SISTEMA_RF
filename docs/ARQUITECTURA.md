# Arquitectura del sistema

Sistema full stack para reconocimiento facial y analítica predictiva de asistencia.

- Frontend: React + Vite + Axios + Recharts.
- Backend: FastAPI, JWT, SQLAlchemy, OpenCV, face_recognition.
- Base de datos: MySQL/XAMPP.
- Módulos: autenticación, estudiantes, biometría facial, asistencia, reportes y analítica.

El reconocimiento usa embeddings faciales de 128 dimensiones y distancia euclidiana con tolerancia configurable.
